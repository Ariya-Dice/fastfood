# FASTFOOD - نسخه Bootstrap

نسخه Bootstrap 5 از پروژه سفارش آنلاین فست‌فود.

## اجرا

```bash
cd bootstrap
npm install
npm run dev
```

سرور روی پورت **3001** اجرا می‌شود.

## تفاوت با نسخه اصلی

| مورد | نسخه اصلی | نسخه Bootstrap |
|------|-----------|----------------|
| CSS Framework | Tailwind CSS | Bootstrap 5 RTL |
| پورت dev | 3000 | 3001 |
| کامپوننت‌ها | Tailwind classes | Bootstrap + react-bootstrap |

## ساخت

```bash
npm run build
npm run preview
```
